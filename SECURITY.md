# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues privately to **security@dustbowl.games** (or via GitHub Private Vulnerability Reporting if enabled on the repository) with:

- Affected repository, service, or endpoint
- Steps to reproduce or proof-of-concept
- Potential impact

We acknowledge reports within **48 hours** and aim to ship verified fixes to `staging` and `production` on an expedited cadence.

## Supported Versions

Only the active default branch (`main` or `staging`) and latest production container digests deployed via `DustBowl-CD` are supported with security patches.
